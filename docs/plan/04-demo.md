## 4.1 The story

Rao Lab, recording day. Maya wants to know whether green-tea catechin EGCG reduces E. coli biofilm at sub-inhibitory concentrations. In 3 minutes 50 seconds, two Mattermost rooms show literature, a retracted citation caught, a booking and reagent order proposed, a student refused, the PI's approval recorded by Switch, an analysis with provenance, a draft with only verified citations, and a data correction that turns the figure and draft stale until re-run.

Honesty rules, visible on screen and in the README:

- A small permanent badge: "Synthetic demo data. PI and student both played by the builder in labeled browser profiles."
- If any scholarly API response is replayed from cache, a caption says "API responses replayed from cache, retrieved <date>".
- Elapsed agent time is shown with honest jump cuts and a caption ("agent worked 41 s"), never sped up silently.
- No claim that a physical experiment was performed for the video.

## 4.4 Rehearsal checklist (before every take)

1. `lq doctor` all green; `lq seed --demo --reset --anchor-date <today>` (fresh ledger, dates correct for the recording day).
2. Docker Desktop running; Console open; server running; Mattermost reachable; `!agents-status` shows 5 live.
3. A fresh project room per take: run the project template with `project=egcg-take<N>` (clean history without deleting anything).
4. `!reset` each agent if it carries context from rehearsal; wait for live.
5. Two Chrome profiles signed in (`prof-rao`, `maya`), zoom 110-125%, same theme, notifications muted, bookmarks bar hidden, 1920x1080, OBS scene ready.
6. Wispr Flow running with dictionary and snippets loaded; microphone tested; mention-first phrasing on a cue card; Wispr style set so no period lands after a mention.
7. Power plan never sleep; Windows Focus Assist on; Docker and Console minimized.
8. Run the Playwright smoke spec (`pytest -m e2e -k smoke`, about 4 min) and confirm pass.
9. No secrets, tokens or private URLs visible in any window or address bar.

## 4.5 Fallback plan if a live agent misbehaves

| Failure | On camera | Off camera |
| --- | --- | --- |
| Agent silent more than 45 s | Type `!agents-status`; if it shows no session, keep rolling: "Switch tells us its session died" (a real feature) | Restart the session in Console, retake the segment |
| Agent wanders (wrong slot, chatter) | Do not argue on camera; cut | Tighten the instructions, add a replay scenario test, retake |
| Approval card does not appear | Cut | Check spike S2 settings and Auto mode; use the CLI `ask` variant if needed |
| Scholarly API outage | Scout reports `UNREACHABLE` honestly (also a feature) | Set `LQ_HTTP_MODE=replay` for the take and show the replay caption |
| Run unrecoverable | - | Record segment by segment (each is reproducible from the seed) and edit with honest jump cuts; keep the raw full-length recording as a backup link |
| Provider down | - | Switch the agent's provider in Console and disclose it in the README |

Never draw fake approval buttons, never present a deterministic replay as a live model run, and never present an offline mock as live Switch.

## 4.6 Recording and editing

- **Baseline first:** record one complete, honest take on Friday evening and keep it untouched as the fallback.
- **Final:** three full takes Saturday 09:00-11:00; pick the best; segment retakes only where needed.
- Edit in Clipchamp (built into Windows) or DaVinci Resolve; burned-in captions; 1080p; upload to YouTube (public or unlisted per organizer guidance) and attach to a GitHub release.
- Pixel pass before export: readable chat text at 1080p, no clipped tables, consistent emoji and heading styles in agent messages, figure fonts legible, cursor movements unhurried.
